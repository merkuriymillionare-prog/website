# NELACOSTE WORK — сайт

Запуск: `npm install` → `npm run dev`. Деплой — как раньше (Vercel).

## Что изменилось
- Плоский стиль без стекла: сплошные тёмные поверхности, аккуратные акцентные цвета.
- Карточки сборок — вариант A: квадрат, скриншот виден целиком на размытом фоне.
- «Подробнее» открывает окно с описанием, списком возможностей, ссылкой на скачивание и (если заполнено поле `review`) кнопкой «Смотреть обзор».
- Каталог: поиск, сортировка (популярные / дешёвые / по названию), фильтр «Все / Бесплатные / Платные».
- Настройки сайта (шестерёнка в шапке): 5 цветов (красный, фиолетовый, синий, зелёный, оранжевый), размер карточек, анимации вкл/выкл. Выбор запоминается в браузере.
- Меньше текста: убран блок «Куда дальше», сокращены описания преимуществ, шагов и HUDLoader.

## Где что менять
- Сборки: `app/builds-data.ts` (поле `review` — ссылка на обзор).
- Цвета тем: `app/globals.css`, блок «ПЛОСКИЙ СТИЛЬ + ТЕМЫ + НАСТРОЙКИ» (`.site[data-theme="..."]`).
- Для лучшего вида карточек можно класть квадратные скриншоты, но широкие тоже показываются целиком.

## Подача: по одному экрану
Сайт больше не одна длинная лента. Вкладки в шапке переключают экраны:
Главная · Сборки · HUDLoader · Цены · Портфолио · Отзывы.
- «Цены» делится на подвкладки: Как купить / Стоимость / Почему мы.
- В HUDLoader сравнение, возможности и состав покупки спрятаны в раскрывающиеся блоки.
- Адрес запоминает экран (`/#builds`), можно кидать прямую ссылку в Telegram.

## Фон и окно «Подробнее»
- Фон: `app/fly-bg.tsx` — плывущие значки из игры (PNG из `public/icons`: 0 кулак, 24 пистолет, 43 камера, 42 огнетушитель), перекрашиваются в цвет выбранной темы. Чтобы добавить значок — положи PNG в `public/icons` и допиши путь в массив `ICONS`, смещение за курсором. Выключается переключателем «Анимации» в настройках, при `prefers-reduced-motion`; на телефонах значков вдвое меньше и нет реакции на курсор.
- «Подробнее»: окно в один экран без прокрутки. Слева скриншот целиком, справа название, цена, теги и вкладки «О сборке / Возможности / Похожие»; кнопки «Скачать / Обзор / Вопрос» всегда внизу. Стрелки ← → на клавиатуре и кнопки ‹ › листают сборки.

## Админка (добавлять сборки и отзывы без кода)
Открывается по адресу **`/admin`** (например `nelacostework.xyz/admin`). Вход по паролю.
Что умеет:
- **Сборки:** добавить, изменить, удалить, дублировать, менять порядок (↑ ↓). Поля: название, цена (бесплатно/платная), скачивания, скриншот, ссылки на скачивание и обзор, описание, теги, возможности. Справа сразу видно, как карточка будет выглядеть на сайте.
- **Скриншоты:** перетащи файл, нажми на область или вставь из буфера (Ctrl+V). Картинка сама сжимается в WebP (до 1600 px), так что сайт не тормозит.
- **Отзывы:** текст, имя, подпись, оценка и **аватарка** (квадрат, обрезается по центру до 256 px).
- **Сохранить на сайт** (Ctrl+S): изменения появляются на сайте через несколько секунд, без пересборки. «Резерв» скачивает копию списка, «Из файла» загружает её обратно.

### Запуск админки на своём компьютере (Windows)
1. Установи **Node.js LTS** (версия 20 или новее) с nodejs.org. Проверка: в терминале `node -v`.
2. Распакуй проект. Самый простой путь: **двойной клик по `start-local.bat`**. Он сам создаст `.env.local`, откроет его в блокноте (впиши пароль в строку `ADMIN_PASSWORD=...`, без `#` в начале), поставит зависимости и запустит сайт.
3. Открой в браузере **http://localhost:3000/admin**, введи пароль.

То же руками: в папке проекта `copy .env.example .env.local` → открой `.env.local`, впиши `ADMIN_PASSWORD=твоя-длинная-фраза` → `npm install` → `npm run dev`.

Локально GitHub не нужен: админка пишет прямо в папку `data/` (сборки в `data/builds.json`, отзывы в `data/reviews.json`, загруженные картинки в `data/uploads/`). Остановить сайт: `Ctrl+C` в окне терминала. Запускай именно `npm run dev` (не `npm start`): на `http://` без HTTPS браузеры могут не принять защищённую cookie входа.

**Как выложить локальные правки на настоящий сайт:** закоммить и запушь в GitHub изменившуюся папку `data/` (там `builds.json`, `reviews.json` и `uploads/`). Vercel задеплоит сайт с новыми данными.

### Как включить (один раз)
1. В настройках хостинга добавь переменные окружения (образец — файл `.env.example`):
   - `ADMIN_PASSWORD` — пароль (минимум 8 символов, лучше длинный).
   - Для **Vercel**: `GITHUB_TOKEN` и `GITHUB_REPO` (`логин/репозиторий`). Токен: GitHub → Settings → Developer settings → Fine-grained tokens, доступ только к репозиторию сайта, Contents: **Read and write**. Админка сохраняет данные коммитами в папку `data/` репозитория (Vercel после коммита может перезапустить деплой — это нормально).
   - Для **своего сервера / локально**: токен не нужен, данные пишутся в папку `data/` рядом с проектом (или в `DATA_DIR`).
2. Передеплой сайт, зайди на `/admin`, введи пароль.

Без `GITHUB_TOKEN` на Vercel админка работает **в режиме просмотра** (сохранять нельзя), чтобы ничего не терялось.

### Где лежат данные
`data/builds.json` (сборки), `data/reviews.json` (отзывы), картинки из админки — `data/uploads/` (отдаются по адресу `/api/img/...`). Файлы можно править и руками, структура описана в `app/builds-data.ts` и `app/reviews-data.ts`.

### Безопасность
**Файл `.env.local` с паролем и токеном нельзя выкладывать в GitHub** (в проекте есть `.gitignore`, который это запрещает; не удаляй из него строки с `.env`).
Пароль не хранится в коде; вход ставит подписанную cookie на 7 дней (HttpOnly, SameSite=Strict); после 6 неверных попыток с одного адреса вход блокируется на 10 минут (на Vercel счётчик живёт в памяти отдельных серверов, поэтому главная защита — длинный пароль из 12+ символов); все данные проверяются на сервере (ссылки только http/https, картинки только WebP/PNG/JPG по содержимому). Страница админки закрыта от поисковиков (`robots.txt`).
